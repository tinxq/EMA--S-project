# 💜 Emo-Tion for English

**Emo-Tion for English** is an interactive English-learning platform designed to help learners improve their English skills through structured learning rounds, level assessment, and personalized learning guidance.

The platform focuses on making English learning more engaging, practical, and motivating rather than relying only on traditional grammar-based lessons.

## 🌸 About the Project

Emo-Tion for English was created to provide learners with a supportive learning experience that combines:

* 📚 English learning resources
* 📝 Level assessment
* 🎧 Listening practice
* 📖 Reading practice
* 💬 Speaking development
* ✍️ Writing development
* 🎯 Personalized learning goals
* 🤝 A supportive learning community
* 🎁 Special offers and learning packages

The platform is designed around weekly **Rounds**, where learners work on the four main English skills while developing vocabulary and grammar appropriate to their level.

## ✨ Features

### 🏠 Home Page

The homepage introduces the platform, its learning philosophy, common English-learning challenges, and the solutions offered by Emo-Tion.

### 📊 English Level Test

The website includes an interactive English placement test with five levels:

* Pre-A1
* A1
* A2
* B1
* B2

Each level contains different questions using:

* Text
* Images
* Audio
* Multiple-choice questions

The system calculates the learner's performance and displays their current estimated level.

### 🎯 Learning Levels

After completing the assessment, learners receive information about their current level and the recommended next level.

The platform provides guidance for progressing through:

`Pre → A1 → A2 → B1 → B2 → C1`

### 💡 Learning Tips

The website provides practical study tips covering:

* Creating a suitable study environment
* Setting short-term and long-term goals
* Staying motivated
* Finding a study partner
* Using additional English-learning resources

### 🎡 Offers Wheel

Users can spin an interactive offer wheel to receive a randomly selected offer color before contacting the platform through WhatsApp.

### 💬 Testimonials

The website includes learner testimonials from different countries, including:

* Saudi Arabia 🇸🇦
* Sudan 🇸🇩
* Egypt 🇪🇬

### 👩‍🏫 About Us

The About Us section introduces **Ms. Eman** and explains the platform's mission, teaching philosophy, values, and future vision.

### 💎 Learning Packages

The platform provides different learning packages, including:

* **Standard**
* **Silver**
* **VIP**

Each package provides different levels of learning support and follow-up.

## 🧪 English Placement Test

The placement test is organized into five stages:

| Level | Focus                                                      |
| ----- | ---------------------------------------------------------- |
| Pre   | Basic vocabulary and simple sentences                      |
| A1    | Basic communication and everyday English                   |
| A2    | Daily situations, past events, and practical communication |
| B1    | Experiences, opinions, vocabulary, and communication       |
| B2    | Advanced vocabulary, comprehension, and complex topics     |

Each level currently contains five questions.
